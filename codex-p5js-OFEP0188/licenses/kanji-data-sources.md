# 漢字・読みデータの出典

## 配当学年
文部科学省「小学校学習指導要領（平成29年告示）」別表「学年別漢字配当表」（2020年度施行）。
https://www.mext.go.jp/content/1413522_001.pdf
学習指導要領LODの構造化データで全1026字と各学年の字数を照合しています。
https://jp-cos.github.io/821/0000100000000
学年別字数：80、160、200、202、193、191。
